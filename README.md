# 노후애(愛) — 고령층 금융 리스크 예측 & 맞춤 자산 추천

## 프로젝트 개요
KOSIS·금융감독원 공공 데이터와 합성 사용자 데이터를 기반으로,
고령층의 자산 부족 위험군을 분류하고 적합 금융상품 Top-3을 추천하는
프로토타입 시스템.

## 본인 담당
- (예: 데이터 전처리 / TabNet 학습 / FAISS 인덱싱)
- 팀 N인 프로젝트 / 본인 기여도 약 OO%

## 파이프라인
1. **위험군 분류** — TabNet (입력: 재무 특성 / 출력: 고/중/저위험)
2. **제약 필터링** — 룰 기반 (나이·소득·신용등급)
3. **유사도 추천** — FAISS L2 인덱스 (사용자 임베딩 ↔ 상품 임베딩)

## 데이터
- 공공 데이터: KOSIS 노령연금 수급자 통계 (실데이터)
- 합성 데이터: 금융감독원 상품정보 기반으로 생성한 가상 사용자 N명
  → 실제 사용자 데이터 미보유로 인한 한계, 프로토타입 단계 검증

## 평가 (프로토타입 기준)
- TabNet 분류 정확도: 65% (test split, N=___)
- FAISS Top-3 추천 적합도: ___ (평가 방식 기재)
- 베이스라인: 키워드 매칭 → +27%p
